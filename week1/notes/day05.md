# Day 5 笔记

1. try/except 的读法：try 里装**想干的事**，except 里装**出错了怎么办**；没有 try 的程序遇到意外时会报一长串天书、然后当场摔死。

2. 重试分类学：401（key 错）**不该重试**（再怎么试都立马报同一个错，那叫固执）；429（限流）**该重试**（用太猛了，歇 2 秒可能就通）。

3. 账本用了什么模式？**累加器**——每收到一块就结算自己那一份，从不回头重算；今天用了四个（次数、输入、输出、钱）。

4. 【加时①】常见错误 → 处理方式清单（自己的话）：
   401 → key 无效：重试无用，先修配置；402 → 欠费：去充值；404 → 模型或地址不对：核对名字和接口；429 → 限流：睡 2 秒再试是对的；网络断 → 睡 2 秒重试，3 次不通就人话退场（今天的断线演练现场）。

5. 成本公式：本轮花费 = **输入 token × 输入单价 + 输出 token × 输出单价**。不一定准，两个原因：①各家计费规则不同（有的把模型悄悄算的 reasoning/草稿 token 单独计价）；②峰值/空闲、缓存命中是两套价（Day 1 那张价格表的伏笔）。

## 今天真正记住的一件事

修不好的错别再试——程序（和人一样）要分得清坚持和固执。
