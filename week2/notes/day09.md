# Day 9 笔记

1. strict schema 的三条军规：**每个字段都要列进 required**（可空用类型数组表达，而不是省略不写）；**每个 object 都要 additionalProperties: false**（不许多塞字段）；**可空字段写成 `{"type": ["number", "null"]}`**。

2. 严格模式解决的是**形状类失败**（非法 JSON、字段缺失、类型漂移、裹围栏）；解决不了**语义/事实类失败**——卡片再工整，内容可以是编的（探针里的 `"2026-05-07"` 就是证据）。

3. 双层重试各治什么病：**网络层**治 429 / 超时 / 断连（3 次 + sleep 2 秒）；**语义层**治「JSON 合法但没有可用的东西」（exercises 为空 / 内容不对）——1 次 + **纠错消息**（先把错答留档，再写清楚错在哪、要什么）。

4. prompt 里格式说明退休，省下的是**每次请求的输入 token**（system 提示词变短，而它每轮都要整包重发），也省了人肉维护一段格式说明的心智成本。

5. 纠错消息要写清两件事：**错在哪**（这次 exercises 是空的）+ **要什么**（按最初的话重新解析；确实没有动作就保持空列表）。
