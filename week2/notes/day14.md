## 阅读补档：function_calling.md（10 分钟）

- Tool / Function 本质是什么？模型自己执行吗？
函数调用。模型不执行，它返回结构化输出给程序，程序调用 API 执行，再把结果返回给模型。

- 一次工具调用里，哪一步是「控制权交接」？为什么这一步必须在程序里？
模型返回结构化输出给程序，这一步是控制权交接。必须在程序里，因为模型没有执行能力：没有网络、文件系统、权限，只能生成 token；程序负责校验参数、调用 API、处理副作用。

- 为什么工具执行结果要作为一条 message 塞回 `messages`？
模型是无状态的，只能看到 `messages` 里的内容；工具结果必须作为一条 message 塞回去，模型才能基于真实结果组织最终回答。

- 工具说明书每轮都要重发，这对输入 token 和成本意味着什么？
工具说明书每轮都要重发；工具越多、描述越长，每轮输入 token 越贵，还占上下文窗口。Day 12 实测带工具的请求输入 339 token，普通对话约 42 token。
